README

Each dataset is created by one of the scripts described in the workflow file. At each step, new columns are added to the dataset.

------------------

Columns in the final dataset

File: 5 - Argos Juv ALL + SI + MLD + MPAs + Fish.csv

-----------------
Column Description:

ID: Unique identifier of the penguin.

Quality: Argos location quality class.

Date: Date of the GPS location, in YYYY-MM-DD format.

Colony: Colony where the penguin was equipped with a biologger.

SI: Sea-ice concentration associated with the GPS location.

MLD: Mixed layer depth associated with the GPS location.

Year: Year of the GPS location, in YYYY format.

MPA: Indicates whether the GPS location is inside (1) or outside (0) any established or proposed marine protected area (MPA).

MPA_Est: Indicates whether the GPS location is inside (1) or outside (0) an established MPA.

MPA_Prop: Indicates whether the GPS location is inside (1) or outside (0) a proposed MPA.

Lon: Longitude of the GPS location.

Lat: Latitude of the GPS location.

Fish: Fishing effort associated with the GPS location.
